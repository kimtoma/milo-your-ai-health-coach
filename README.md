# 🐾 Milo (마일로) — Web & Cloud Run Edition
> **GLP-1 비만 치료 및 멘탈 케어를 위한 살아 숨 쉬는 AI 건강 컴패니언**

이 프로젝트는 기존 Android (Jetpack Compose) 기반의 **Milo (마일로)** 애플리케이션을 **React + TypeScript + Vite + Express (Cloud Run 호환 풀스택 웹 애플리케이션)**으로 완벽하게 재작성한 버전입니다.

---

## 주요 기능 (Core Features)

### 1. 살아 숨 쉬는 마일로 (14종 상태 머신 & 탄성 물리 캔버스)
- **말랑한 탄성 인터랙션**: 마일로의 배나 볼을 클릭/터치하면 탄성 물리 효과와 함께 볼이 발그레해지며 반응합니다.
- **실시간 음성 데시벨 오라**: 음성 교감 모드 활성화 시 물방울 뿔과 동심원 오라 링이 호흡 및 음성에 맞춰 반응합니다.
- **14종 캐릭터 모션 & 3방향 뷰 (`정면 Front` / `측면 꼬리 Side` / `뒷모습 Back`)**:
  - **감정·이벤트 6종**: `기쁨/칭찬`, `경청/공감`, `걱정/부작용 공감`, `GLP-1 주사 & 케어`, `식단 & 카운팅`, `체중 기록 완료`
  - **운동 모션 8종**: `신나게 걷기`, `가볍게 뛰기`, `스쿼트 준비`, `스쿼트 동작`, `자전거 타기`, `근력 운동`, `요가 & 스트레칭`, `계단 오르기`

### 2. Zero-Effort 확인형 건강 기록 (Human-in-the-Loop)
- 사진첩 음식 사진(연어 포케 볼 등) 및 걸음 수·수면 데이터를 마일로가 먼저 제시하고, 사용자가 **[원터치 승인]** 버튼으로 최종 승인할 때만 건강 일기에 반영됩니다.
- **[식단 사진 분석]** 버튼을 통해 로컬 이미지를 업로드하면 서버 측 Gemini Vision API(`/api/analyze-food`)를 통해 영양 및 단백질 피드백 카드를 생성합니다.

### 3. GLP-1 6구역 주사 부위 로테이션 & 부작용 케어
- **6구역 신체 로테이션**: 복부 4분면(좌상·우상·좌하·우하) 및 양측 허벅지 투여 주기를 추적하고 오늘의 추천 부위(`복부 우하단 ⭐`)를 안내합니다.
- **부작용 & 감정 문진**: 주사 후 오심(울렁거림), 피로감, 식욕 억제 상태와 오늘의 감정 상태를 함께 기록합니다.

### 4. 병원 제출용 Medical Bridge 리포트 & 파일 내보내기
- 최근 4주간 체중 감량(`78.3kg → 74.2kg`) 및 골격근량 유지(`28.4kg → 28.2kg`) 추이 차트와 임상 요약을 생성하며, 진료실 제출용 리포트 이미지/문서 다운로드를 지원합니다.
- **폴드 7 자세 전환 시뮬레이터**: `펼침 대화면 (Unfolded)`, `플렉스 모드 (Flex 115°)`, `커버 화면 (Cover)` 및 좌우 패널 스왑·비율 슬라이더를 웹 환경에서 그대로 제공합니다.

## 실행 및 배포 (Development & Cloud Run Deployment)

```bash
# 의존성 설치
npm install

# 개발 서버 실행 (Port 3000)
npm run dev

# 프로덕션 빌드 및 실행
npm run build
NODE_ENV=production npm start
```
